# Native Pi /rev Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship and install native Pi `/rev` support.

**Architecture:** A root Pi package exposes a dependency-free command extension and generated Pi skill. Existing provider CLI transports retain the review evidence contract; Pi becomes an explicit host in roster, workhorse and phase routing.

**Tech Stack:** JavaScript ESM, Python standard library, Bash, Pi Git packages.

**Spec:** `docs/superpowers/specs/2026-11-11-pi-rev-design.md`

## Global Constraints

- `/rev` only; no Pi stack hosting or new reviewer transport.
- No implicit Anthropic Agent fallback or credential migration.
- Preserve evidence, effort, recovery, receipt and publication requirements.
- Normal independent review only for this repository.
- Full gates run in CI at the exact candidate revision.

## Review Focus

- Shared `rev` skill collisions must not select another host's workflow.
- Arguments containing quotes or shell substitutions remain plain text.
- Busy or nested invocation must not start concurrent review orchestration.
- Pi hosts without Claude CLI must not invent an Agent seat.
- Fresh install must load `/rev` and its phase files without build steps.
